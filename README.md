# 蓬蓬科普 Pengpeng Health
# 老年肿瘤患者用药科普个性化推荐网站

---

## 项目简介

蓬蓬科普是由重庆大学附属肿瘤医院药学部创建的创新性医药科普平台，致力于为老年肿瘤患者及其家属提供专业、易懂、个性化的用药科普信息。

### 特色功能

- **中英文双语支持**：一键切换中英文界面
- **用药知识库**：提供全面的药物信息、适应症、用法用量等专业内容
- **个性化推荐**：根据用户画像提供精准的科普内容推荐
- **专题区**：包含文档和视频资源的专题科普内容
- **分面检索**：多维度筛选，快速定位所需内容
- **适老化设计**：大字体、简洁界面，适合老年用户

## 本地运行

### 方法一：直接打开

直接在浏览器中打开 `index.html` 文件即可查看网站。

### 方法二：使用本地服务器

推荐使用本地服务器以获得最佳体验：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js (需要先安装 http-server)
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 部署指南

### 选项 1：GitHub Pages（推荐，免费）

1. 创建 GitHub 仓库
2. 将代码推送到仓库
3. 在仓库设置中启用 GitHub Pages
4. 选择主分支作为发布源

1. 将所有文件上传到虚拟主机的 `public_html` 或 `www` 目录
2. 确保 `index.html` 在根目录
3. 访问您的域名

## 语言切换

网站支持中英文双语切换：

- 点击右上角的语言按钮（中文/English）
- 语言偏好保存在本地存储中
- 刷新页面后自动保存选择

---

## 个性化推荐逻辑

个性化中心根据用户输入的信息生成推荐：

1. **基本信息**：年龄段、性别
2. **肿瘤信息**：肿瘤类型、治疗阶段
3. **治疗方案**：化疗、靶向、免疫等
4. **症状**：疼痛、恶心、乏力等
5. **合并疾病**：高血压、糖尿病等

系统根据以上信息匹配相关知识库内容，提供个性化推荐。
